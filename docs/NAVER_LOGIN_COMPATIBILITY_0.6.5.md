# 네이버 로그인 호환성 개선 (0.6.5)

## 확인한 코드 문제

문제가 발생했다는 다른 PC의 로그와 운영체제 정보는 아직 받지 못했다. 아래는 저장소에서 확인하고 재현 테스트로 검증한 실패 경로다.

| 문제 | 개선 |
|---|---|
| Chrome 기본 경로 일부만 탐색 | Windows Chrome·Edge 및 사용자별 설치, Mac의 전역·사용자 Applications 경로 탐색 |
| Chrome 부재를 브라우저 부재로 판단 | Chrome이 없으면 설치된 Edge 사용. 두 브라우저의 로그인 프로필 분리 |
| 브라우저 실행 오류 이벤트가 처리되지 않음 | 실행 권한·설치 문제를 오류로 반환하고 끊긴 연결 정리 |
| 저사양·느린 PC의 브라우저 시작 제한이 8초 | 연결 대기를 30초까지 허용하고 실패 시 대응 방법 안내 |
| 로그인 탭을 닫아도 대기가 10~15분 남음 | 탭 생존 확인 후 대기 해제, 다음 클릭으로 새 탭 생성 |
| 반복 클릭 시 아무 동작 없이 반환 | 같은 로그인 탭을 앞으로 표시 |
| 자동 로그인과 직접 로그인 창이 경쟁 | 인증 중인 탭을 공유하고 직접 로그인 중 자동 입력 중단 |
| 자동 로그인 시작 API가 인증 완료까지 응답 지연 | 시작은 즉시 응답, 진행·실패는 상태와 로그로 전달 |
| 저장 계정이 있으면 직접 로그인 버튼 숨김 | 저장 유무와 관계없이 직접 로그인·QR 로그인 진입 제공 |
| 대기 중 웹 로그인 버튼 비활성화 | 다시 클릭해 창을 표시하거나 닫힌 창 복구 가능 |
| 브라우저 쿠키 조회 오류를 로그아웃으로 오판 | 연결 실패와 미로그인을 구분, 만료된 쿠키 제외 |
| 인증 시간 만료 시 사용자가 보던 탭 손실 | 창을 보존하고 다시 확인할 수 있도록 안내 |

직접 로그인에는 도우미의 비밀번호 저장이 필요 없다. 보안문자·QR·추가 인증은 네이버가 제공하는 브라우저 화면에서 사용자가 완료한다. 네이버의 인증 정책이나 회사 PC의 실행 제한을 우회하지 않는다.

## 검증

- 기존 신뢰성·소싱 API 테스트 33개 통과.
- 로그인 테스트 12개 통과: 브라우저 탐색, 동시 클릭, 탭 닫기·재시도, 인증 화면 인계, 빈 탭·닫힌 자동 로그인 탭 복구, 시간 만료, 실행 및 인증서 오류.
- 전체 TypeScript 검사 통과.
- 도우미 발견 규약, 기존 대표이미지·상품명·속성어 정책 검사 통과.
- 0.6.5 릴리스 노트 검사 및 runtime 동기화 검사 통과.
- 이 Windows PC에서 **실제 Chrome과 Edge 모두** 한글 프로필 경로, 실행, 테스트 쿠키 저장 후 재시작, 창 표시·종료 통과. 개인 프로필과 실제 네이버 인증정보는 사용하지 않았다.
- 최종 패키지의 main·renderer·runtime 코드 파일 82개가 원본과 해시 일치.

Edge의 CDP 호환성은 [Microsoft 공식 문서](https://learn.microsoft.com/en-us/microsoft-edge/devtools/protocol/)에서도 확인했다. Mac 설치 경로는 자동 테스트로 확인했으며 Mac 실기 검증은 하지 않았다.

## 적용 상태와 남은 확인

- **0.6.5 Windows 설치 파일 생성 및 이 PC 설치 완료**. 설치 프로그램 종료 코드 0, 실행 중 /health 버전 0.6.5, 렌더러 버전 0.6.5·API 연결·탭 5개 확인.
- 설치된 main·renderer·runtime 코드 82개도 저장소와 해시 일치.
- 실제 /naver-ingest/login 요청은 **9ms**에 시작 응답을 반환했다. 직접 로그인 창 대기 상태와 자동 로그인 중단을 확인했다. 사용자의 네이버 인증 완료까지 자동으로 대신하지는 않았다.
- 설치 파일: worker/desktop/dist/MegaloadDesktop-Setup-0.6.5.exe (182,672,726 bytes).
- 웹 로그인 버튼 개선은 저장소에 준비됐으며 운영 웹 배포는 하지 않았다.
- 다른 사용자에게 자동 업데이트를 배포하지 않았다. master 푸시는 데스크톱 릴리스 워크플로를 통해 전체 업데이트 피드를 바꾸므로 배포 범위를 확인한 뒤 진행한다.
- 문제가 발생한 PC에서의 실제 계정 로그인 완료는 아직 확인하지 못했다. 브라우저 사용이 정책상 차단된 PC, 네이버가 계정 인증을 거부하는 상황까지 무조건 로그인된다고 보장할 수는 없다.
